# GraphFlow VS Code Extension

GraphFlow extension adds quick commands for running task orchestration and viewing run history.

## Commands

1. `GraphFlow: Run Task`
2. `GraphFlow: Show Runs`

## Development

```bash
npm install
npm run build
```

## Package

```bash
npm run package
```

This command generates:

`../artifacts/graphflow-vscode-0.1.0.vsix`
