# GraphFlow v0.1.0 Release Notes

Release date: 2026-05-28

## Highlights

1. End-to-end orchestration available from CLI and runtime exports.
2. Graph-based context control with automatic run-time graph sync.
3. Near-lossless token compression pipeline with dual-channel context and dynamic refill.
4. Workspace graph indexing and context preview tooling.
5. VS Code extension scaffold connected to GraphFlow runtime.

## Major Capabilities

1. Task orchestration
- simple/complex triage
- DAG planning and execution
- retry and human-review fallback

2. Context and graph
- in-memory graph store and Graphify MCP HTTP transport
- post-run graph synchronization
- layer-aware context budgeting

3. Cost and quality controls
- model tier routing (smart/economy)
- provider fallback
- learning data export and canary gate

## CLI Commands

1. `npm run start -- run "<task>"`
2. `npm run start -- context preview "<query>"`
3. `npm run start -- graph index [path]`

## Packaging

1. Build extension:
- `npm --prefix vscode-extension run build`

2. Create `.vsix` package:
- `npm --prefix vscode-extension run package`
- output: `artifacts/graphflow-vscode-0.1.0.vsix`
