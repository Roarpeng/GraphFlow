# GraphFlow v0.3.0 Release Notes

- Date: 2026-05-28
- Status: Released

## Highlights

1. Skill flywheel is now online: GraphFlow learns reusable skill atoms from task outcomes.
2. Learned skills are connected with `co_occurs` edges and reused as planning hints.
3. Dynamic routing is diagnosable with explicit health and provider choice output.
4. Nightly learning workflow is executable from CLI and chat.
5. VS Code extension is now self-contained: packaged runtime, chat entrypoints, and interactive observability panels are included in the VSIX.
6. CI workflow is fully in place for lint/build/test/extension-build.

## New Capabilities

1. Skill flywheel
- Skill extraction from task text
- Skill scoring and usage accumulation
- Skill graph updates (`Skill` nodes + `co_occurs`/`improves` edges)
- Planner skill hint injection

2. Runtime and CLI
- `graphflow route diagnose`
- `graphflow learn nightly`
- `graphflow graph inspect`
- `graphflow skill insights`

3. VS Code chat participant
- `@graphflow /diagnose`
- `@graphflow /learn`
- `@graphflow /graph`
- `@graphflow /skills`

4. VS Code observability panels
- `GraphFlow: Graph Snapshot`
- `GraphFlow: Skill Insights`
- Graph Snapshot supports node search, node-type filtering, node focus, and relation highlighting
- Skill Insights supports search, outcome filtering, and score/usage/time sorting
