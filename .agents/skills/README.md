# Agent / Cursor skills (project)

This repo vendors [emilkowalski/skills](https://github.com/emilkowalski/skills) for design-engineering taste:

- Installed via `npx skills@latest add emilkowalski/skills`
- Source copies: `.agents/skills/*`
- Cursor symlinks: `.cursor/skills/*` → `.agents/skills/*`
- Lockfile: `skills-lock.json`

Primary skill for GraphFlow webview UI: **emil-design-eng** (press feedback, ease-out, soft elevation, reduced motion).
